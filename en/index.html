Clickmouse

A fast, simple, lightweight mouse autoclicker made with Python

Get Started
View Source Code
⬇️

Rich Clicking Features

Offers extensive clicking functions, including setting click count, interval, default click properties, hotkey clicking, etc.

⚙️

Abundant Settings

Can configure theme, default click count and interval; use default values on errors, etc.

♻️

Lightweight

Simple UI, easy to use, and lightweight.

🔄️

Auto Update

Software auto-updates to ensure you have the latest version.

🖥️

Background Running

Can run in the background without interrupting your work; can be woken up or start clicking via hotkeys.

🧩

Highly Extensible

The software can be extended by importing extensions for more functionality.

💻

Easy Development

Extension development is simple; just use the clickmouseAPI library to create.

Command Line & CLI

Supports more lightweight command line and CLI modes, easily callable by other software.

🎀

Installation Assistant

The official installation assistant makes it easy to configure clickmouse and package manager, simplifying your operations.

📦

Package Manager

Officially supports a package manager for easy installation, uninstallation, and updating of extensions.

🔛

Open Source

This software is open source under the MIT license. You can modify, distribute, use, or even charge for it. You can also suggest improvements to the clickmouse team. Source code：https://github.com/xystudiocode/pyclickmouse.
