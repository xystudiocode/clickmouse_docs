# 3.2.0.19beta9
发布日期：2026/02/18

## 更新内容

- 大幅精简组件，优化代码结构，提升性能并压缩安装包体积。
- 修复了一些bug:
- - 修复了英语模式无法启用无限连点的问题。
- - 修复了英语模式"已暂停"显示错误的问题。
- - 修复了如果你的语言是中文，最大值的单位将显示为英文的问题。
- - 修复了无法确认安装，需要点击取消安装的问题
- 添加新功能的英语翻译
- 移除了“帮助”菜单的热键帮助，因为现在有了自定义热键。
- 修改默认响应延迟为100ms，1000ms的延迟过于卡顿。
