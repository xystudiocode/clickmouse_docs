# 快速开始

欢迎使用我们的文档！本指南将帮助您快速入门。

## 前提条件

在开始之前，请确保您已安装：

- Node.js 16 或更高版本
- npm 或 yarn 包管理器
- 基本的 Markdown 知识

## 安装

### 使用 npm

```bash
npm install -D vitepress
```

### 使用 yarn

```bash
yarn add -D vitepress
```

## 快速开始

1. 创建新项目：

```bash
mkdir my-docs && cd my-docs
```

2. 初始化项目：

```bash
npm init -y
```

3. 安装 VitePress：

```bash
npm add -D vitepress
```
