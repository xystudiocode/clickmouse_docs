# Features

Clickmouse has many features, all located in the menu section:

- File:
- - Clear Cache: Clear cache to free up memory.
- - Exit: Exit the program.
- Settings: Configure various parameters of the software.
- Update:
- - Check for Updates: Check if there are software updates.
- - Update Log: View the update log.
- Help:
- - About: View software version, author, and license information.
- - Hotkey Help: View software hotkeys.
- - Help: View clickmouse documentation.
- - Feedback: Send feedback to the author.
- Extensions:
- - Official Extensions:
- - - Manage Extensions: Install and uninstall extensions via clickmouse's package manager.
- - - Extension Software: Official extension software, see [Extension List](./extensions/).
