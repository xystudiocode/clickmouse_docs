# 3.0.0.11rc1

Release Date: 2025/12/13

## Update Content

- UI rebuilt with PySide6, giving the interface a fresh look
- New settings content
- Added hotkey startup; see software help for hotkeys
- Added click count input functionality
- Added status bar to view clicking status
- Temporarily disabled features originally planned for version 2.3.0, postponed to 3.1.0.12
- Fixed some bugs
