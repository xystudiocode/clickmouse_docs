# 3.0.1.12

Release Date: 2025/12/20

## Update Content

- Optimized language packs:
- - Modified English language pack, fixed missing spaces in version number characters, removed extra commas
- - Other language pack optimizations...
- Automatic uninstall functionality for erroneous styles
- Fixed some bugs:
- - After switching language, the next opened interface becomes the newly selected language, causing interface inconsistency
- - Fixed issue where English language pack has unexpected characters
- - Other bug fixes...
- - Adjusted settings: Changed "Software requires restart" interface to a popup and removed character display
- - Removed clickmouse initialization, now automatically detects language
