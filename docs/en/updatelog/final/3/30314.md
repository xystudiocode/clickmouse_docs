# 3.0.3.14

Release Date: 2026/01/11

## Update Content

- Fixed some issues:
- - Issue with English language pack having unexpected characters
- - When settings are turned on then off, changing Windows theme shows settings
- - After settings trigger restart, returns to first page
- - When hovering over menu, status bar characters disappear
- - In some cases, clicker ending doesn't cause button display changes
- Added preserve settings tab page functionality
- Now clicker settings or time changes cannot be made while clicker is running to avoid confusion
- Modified styles:
- - Consolidated styles into one file
- - Removed no-style mode
- - Fixed some style display bugs
- - Added style boundary protection
