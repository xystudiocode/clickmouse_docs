# 3.1.2.17

Release Date: 2026/01/31

## Update Content

- For beta versions, all clickmouse component icons have 'pre' text below them
- New dialog box version; dialog box options are now translated to Chinese, multilingual version coming soon
- Fixed bug where clear cache tool checkboxes become unresponsive after selecting "Select All"
- Fixed issue where response delay slider displays as 1
- Fixed auto-start on boot not working issue
- Refactored clickmouse cache clearing tool
- Modified logs; now outputs less text and is easier to manage
- Now cache calculation filters undeletable files for more accurate calculation
- Performance optimization
- Added setting delay setting
- Optimized clicker settings display
- Modified update log
- Fixed auto-start on boot showing "langs.json does not exist"
